# /learner — 스킬 추출

디버깅이나 문제 해결 과정에서 발견한 비자명적 지식을 재사용 가능한 스킬로 추출합니다.

## 추출 조건 (3개 모두 충족)
- "5분 안에 구글링할 수 있는가?" → NO
- "이 코드베이스에 특화된 것인가?" → YES
- "실제 디버깅 노력이 필요했는가?" → YES

## 추출 신호
- 깊은 조사가 필요했던 트리키한 버그 해결 후
- 코드베이스 특유의 비자명적 우회 방법 발견
- 잊으면 시간 낭비하는 숨겨진 함정 발견
- 프로젝트에 영향을 주는 문서화되지 않은 동작 발견

## 저장 위치
- 프로젝트 수준: `.claude/skills/learned/<skill-name>/SKILL.md`

## 파일 형식

```markdown
---
name: <skill-name>
description: <one-line description>
---

# [Skill Name]

## 핵심 통찰
발견한 원칙 (코드가 아닌 사고 모델)

## 중요성
이것을 모르면 무엇이 잘못되는가?

## 인식 패턴
이 스킬이 적용되는 상황을 어떻게 알 수 있는가?

## 접근법
의사결정 휴리스틱 (복사-붙여넣기가 아닌 사고 방식)

## 예시 (선택)
원칙의 설명으로서의 코드
```

## 안티패턴 (추출 금지)
- 일반적인 프로그래밍 패턴
- 리팩토링 기법
- 라이브러리 사용 예시
- 타입 정의나 보일러플레이트
- 주니어 개발자가 5분 안에 검색할 수 있는 것
