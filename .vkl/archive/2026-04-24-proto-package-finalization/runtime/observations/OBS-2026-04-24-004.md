## Causal Interpretation (VKL)

v1 실패 원인:
- FT-02 Hidden Semantic Rule Misfill — 로컬 인접 규칙 (2 socket grammar) 만으로
  거시 도메인 규칙 ("시가지 = 블록 격자") 을 근사하려 함.
- PROP-2026-04-24-001 OR-P-006 이 정확히 예방하려던 실패 유형이 재현.

v2 성공 축:
- **영역 구조 축** 에서 다양성 주입 (OR-P-006 우선 축 원칙): 도로 분할 + 블록 밀도.
- WFC 는 미시 검증자로 축소 — 거시 구조는 pre-plan.
- 수정된 축: (이전에 시도했던) 회전 jitter / 색상 variation 이 아닌, **도메인 고유 구조**.

## Hypothesis for Follow-up (for OR-08 evaluation)

v2 에서도 개선 여지:
- H1. 도로 위계 가시화 — 현재 모든 도로 width=1. Arterial 을 2셀로 하면 격자에 위계 생김.
  단 2셀 도로는 T-junction tile 분류가 복잡 (현재 tileset 은 1-wide 전제).
- H2. Building lot subdivision 깊이 증가 — 현재 BuildingFootprint=0.85 로 lot 당 1빌딩.
  CityscapeGenerator 원본은 lot 재분할로 lot 당 여러 빌딩.
- H3. Park 블록 시각 차별화 — 현재 park 블록은 grass-bush 통일. bush 밀도를 높이거나
  planter 경계 셀 추가 가능.

H1/H2 는 도메인 룰 레벨 (OR-P-006 준수 — 영역 구조 축).
H3 은 블록 내부 디테일 — 여전히 도메인 축 안.
