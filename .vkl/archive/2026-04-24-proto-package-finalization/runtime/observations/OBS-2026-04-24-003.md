# OBS-2026-04-24-003 — 장르별 완전 분리 프리팹 전략 확정

## Observation

사용자가 질문 C-1(캐릭터 프리팹 전략)에 대해 **"(2) 장르별 완전 분리"** 로 응답.

HYP-2026-04-24-001 C-1의 "공통 Unit_Base + 장르별 variant 파생" 가정은 **기각(rejected)** 됨.

## 확정 규칙

- **Rule:** 3장르 각각이 독립적인 프리팹 계층을 가진다. `Unit_Base.prefab`은 공통 베이스가 아니라 현재 프로토 데모용 샘플로만 취급한다.
- **파생 규칙:**
  - turn3d 프리팹 네임스페이스: `Assets/Proto/Prefabs/Turn3d/` (`Turn3d_Party_*.prefab`, `Turn3d_Enemy_*.prefab`)
  - td 프리팹 네임스페이스: `Assets/Proto/Prefabs/TD/` (`TD_Builder.prefab`, `TD_Enemy_*.prefab`, `TD_Tower_*.prefab`, `TD_PowerHub.prefab`, `TD_RelayHub.prefab`, `TD_Core.prefab`)
  - rail-shooter 프리팹 네임스페이스: `Assets/Proto/Prefabs/RailShooter/` (`RS_Enemy_Zombie.prefab`, `RS_CoverSlot.prefab` 등)
- **코드 재사용 범위:** 시스템 코드(MovementAgent, CameraRig, AStarGrid, WFC, PCG, SpeechBubble, ShaderFx)는 재사용 가능. 프리팹 수준의 재사용만 금지.

## 근거

- **OR-08 (Human Oracle):** 사용자 명시적 선택 "(2) 장르별 완전 분리"
- **위계:** 1(최상위) — 다른 모든 오라클 우선

## 함의

1. `Unit_Base.prefab`은 보존하되 Proto_Launcher 외 다른 장르 씬에서는 사용하지 않는다.
2. 각 장르 씬 진입 시 해당 장르 전용 프리팹 디렉토리에서 에셋 로드.
3. Asset Addressables 그룹 분리 시 장르별 label(`turn3d`, `td`, `rail-shooter`)로 분리 검토 (FT-P-002 대비).
4. 장르별 프리팹 독립성 덕분에 FT-02(Hidden Semantic Rule Misfill) 위험 감소.

## C-2 (SpeechBubble 역할) 상태

C-1이 "장르별 완전 분리"로 결정되면서 C-2 역시 **각 장르 내에서 독립 결정** 가능. 전역 정책 없이 각 장르 Phase 진입 시 OR-08 별도 확인.

- **Phase 0 디폴트:** 런처 씬에는 SpeechBubble 미사용. 3개 껍데기 씬에도 미배치.
- **확정 시점:** Phase 1(TD)·Phase 2(Turn3d)·Phase 3(Rail-shooter) 각각 착수 전 OR-08.
