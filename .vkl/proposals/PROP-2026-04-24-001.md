```markdown
### OR-P-006: PCG Domain Rule Oracle (PCG 도메인 룰 오라클)

| 항목 | 내용 |
|------|------|
| **Overlay Of** | OR-01 (Spec Oracle) |
| **Definition** | 절차 생성(PCG) 모듈이 **도메인 고유의 암묵적 배치 규칙**을 준수하는지
  판정한다. 배치 규칙은 현실성(시가지/던전/숲 등) 또는 게임 레벨 디자인 의도
  (플레이어 동선, 전투 공간, 시야)로부터 유래한다. |
| **When to Use** | 1. 새 PCG 모듈 설계 초기 — "다양성을 어느 축에서 주입할지" 결정 전.
  2. 시각 판정 (OR-08) 이 REJECTED 된 후 원인 축을 분류할 때.
  3. PCG 결과가 수치 오라클은 통과했으나 도메인 위화감을 주는 경우. |
| **Limitations** | 1. 도메인 룰이 프로젝트별로 다르므로 매번 명세 필요.
  2. "현실성" vs "게임 디자인 의도" 충돌 시 OR-08 에스컬레이션 필요. |
| **Connected FT** | FT-02 (Hidden Semantic Rule Misfill), FT-01 (Spec Gap) |

**사용 예 — 시가지 PCG 도메인 룰**:
- 건물은 도로 축에 정렬 (yaw jitter 금지)
- 다양성 축은: 도로 위계 / 간격 / 끊긴 길 / 광장 (영역 구조 레벨에서 찾는다)
- 건물 회전/형태 무작위화로 "다양성 부족" 을 해결하려 하면 FT-02 혐의
```

### C. `design/proto-modules/_conventions.md` 에 Hard Rule 신설 (장기 과제, 선택)

```markdown
### HR-PCG-City-01. 시가지 PCG 건물은 도로 축 정렬
- 시가지 계열 PCG (cityscape / urban / district) 가 배치하는 건물 매스는
  도로 축에 정렬한다. 회전(yaw) jitter 금지.
- 다양성은 **도로 위계(Local/Collector/Arterial), 블록 간격, 끊긴 길, 광장**
  등 영역 구조 레벨의 축에서 주입한다.

### HR-PCG-City-02. PCG 다양성 축 우선순위
- 새 PCG 모듈 설계 시, "다양성 부족" 해결책은 다음 순서로 탐색:
  1. 영역 구조 (도로·블록·광장 배치)
  2. 클래스 분포 (블록 타입, 건물 용도)
  3. 크기·높이 분포 (power curve 등)
  4. 회전·색상 jitter (선택적, 도메인 룰 위반 없을 때만)
- 1·2 를 건너뛰고 바로 3·4 로 가는 것은 FT-02 혐의.
```

## Reason

`CL-2026-04-24-001` 및 `CL-2026-04-24-002` 루프에서 사용자로부터 "PCG 결과가
너무 균일함" (OR-08 REJECTED) 피드백을 받았고, Claude 는 이에 대한 대응으로
건물 yaw jitter (±4°) 를 주입했다.

후속 루프에서 사용자가 지적: **시가지 건물은 도로 축에 정렬되는 것이 도메인
관행이며, yaw jitter 는 "다양성" 문제의 잘못된 축을 건드리는 해결책**이다.
진짜 다양성 축은 도로 위계·블록 간격·끊긴 길·광장 등 영역 구조 레벨에 있다.

이 시점까지 Claude 는 VKL 오라클을 **사후 runtime 기록용** 으로만 사용하고
있었다. 즉 OR-01 (Spec Oracle) 을 통해 "시가지 도메인의 암묵 규칙" 을 판단
전에 체크하는 VKL 사이클을 실행하지 않았다. 이로 인해 FT-02 (Hidden
Semantic Rule Misfill) 에 해당하는 오류가 발생하고, 사용자 지적이 있어야만
교정되는 상태가 되었다.

본 proposal 은 이러한 재발을 막기 위해 **PCG 전용 Project Oracle** (OR-P-006)
을 신설하고, 필요 시 Proto 컨벤션에 **HR-PCG-City-01/02** 를 Hard Rule 로
승격하는 안을 제시한다.

## Risk of Adoption
- OR-P-006 은 PCG 모듈이 복수 장르(시가지 / 던전 / 숲 / TD 맵) 에서 요구하는
  룰이 **서로 다를** 가능성이 있다. 본 오라클 자체는 "도메인 룰을 명세한 뒤
  그에 일치하는지 판정" 하므로 범용적이지만, 룰 명세 누락 시 여전히 FT-01 으로
  떨어질 수 있다 → 장르별 `_conventions-<genre>.md` 에 PCG 룰 섹션을 추가하는
  후속 proposal 필요.
- HR-PCG-City-01 은 시가지 계열에 한정되므로 전체 `_conventions.md` 가 아닌
  장르별 컨벤션 파일에 두는 것도 선택지.
- "건물 yaw 정렬" 규칙은 특수 연출(지진, 무너진 도시 등) 에서는 반례가 존재.
  완화 방안: 규칙 본문에 "기본 전제: 평시 시가지" 를 명시하고, 예외는 별도
  연출 파라미터로 허용.
