## 관찰 내용

Rev A (`ProtoEnv_BushBillboard.shader` 초기 구현) 의 부쉬 렌더링이
비교군 URP Lit 구 대비 **방향성 조명 감각이 현저히 약함**.

### 재현 조건
- 씬: `BushDemo.unity`
- 조명: 단일 Directional Light (Euler (55, 35, 0), intensity 1.25, 색 (1.0, 0.97, 0.88))
- Ambient: URP 기본값 (Skybox 기반)
- 카메라: 궤도 회전 (주기 약 25초), 중심 (0, 0.7, 0), 반지름 5.5

### 정량 근거 (코드 읽기)
Rev A 조명 계산:
```
halfLambert = saturate(dot(N, L)) * 0.5 + 0.5;   // 범위 [0.5, 1.0]
directLit   = mainLight.color * halfLambert;
col         = albedo * (directLit + _AmbientColor.rgb) + albedo * back;
_AmbientColor 기본값 = (0.22, 0.28, 0.18)
```

실질 명암비 계산 (mainLight.color = (1,1,1), 무백라이트 가정):
- 직사광 측: `1.0 + 0.22 ≈ 1.22 * albedo`
- 그림자 측: `0.5 + 0.22 ≈ 0.72 * albedo`
- **대비비 1.22 / 0.72 ≈ 1.70×**

URP Lit(표준 Lambert+GI) 비교군은 대비비가 일반적으로 3~6× 수준.
따라서 시각적으로 부쉬가 "평면적" 으로 보이는 결과.
