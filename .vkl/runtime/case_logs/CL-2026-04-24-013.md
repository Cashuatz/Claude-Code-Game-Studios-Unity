## [Knowledge Assets Updated]

### New Hidden Semantic Rules Discovered
- **Unity Input System 전환 프로젝트의 EventSystem 구성 규칙:** `StandaloneInputModule` 사용 금지, 반드시 `UnityEngine.InputSystem.UI.InputSystemUIInputModule` 사용. Proto 프로젝트의 `ProjectSettings/InputManager.asset` 또는 Input System Package 설정 확인이 EventSystem 생성 코드 작성 전제 조건.
- **DDOL 씬과 find_gameobjects 한계:** MCP `find_gameobjects`는 활성 씬만 검색. DDOL 오브젝트는 간접(에러 없음) 혹은 별도 API로 확인.
- **기록 위치:** 본 case log (CL-2026-04-24-013)

### Failure Patterns Cataloged
- **"관용 패턴 misfill"**: `EventSystem + StandaloneInputModule` 조합이 Unity UGUI 관례지만 프로젝트별 Input Settings에 따라 잘못된 선택이 됨. 향후 UI 씬 구성 코드 작성 전 반드시 Input Settings 확인.
- **"Play Mode Stop 잔재 에러"**: DDOL 씬 cleanup 단계에서 missing script 에러가 발생해도 Phase 0 기능 정상. 신규 이슈와 잔재 이슈를 분리 분류하는 것이 Oracle 판정 정확도에 중요.
- **기록 위치:** 본 case log

### Oracle Effectiveness Notes
- **Console clear 후 Play Mode 진입** 패턴이 Input System 호환성 검증에 결정적이었음. Clear 없이는 이전 에러가 섞여 판정 불가.
- **Play Mode 진입/유지 vs Stop** 로그 분리로 FT-11 잔재를 Phase 0 코드와 분리 가능.
- **`execute_code` CMD 길이 제약**이 런타임 시뮬 자동화의 반복적 블로커. 향후 Editor 헬퍼 함수로 Play Mode 테스트를 분리해야 함 (e.g., `Proto/Phase0_RuntimeSmoke` 메뉴에서 버튼 시뮬 + 씬 전환 + Assert).
- **기록 위치:** 본 case log
