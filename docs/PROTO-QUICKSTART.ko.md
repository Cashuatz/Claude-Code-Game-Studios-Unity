# PROTO 퀵스타트 — 1페이지 가이드

## 이 브랜치는?

**프로토타이핑 경량 버전**입니다. 20시간 이내에 **3분짜리 플레이 가능한 유니티 게임**을 만들 수 있습니다.

- 너는 **아이디어만** 말합니다 (한국어로).
- Claude가 **코드·저장·커밋·Unity 작업**을 다 합니다.
- Unity 개발·Git·프로그래밍 지식이 없어도 됩니다.

---

## 4단계 시작

1. **아이디어 한 문장으로 말하기**: 그냥 채팅에 한 줄 쓰면 됩니다. 별도 명령·슬래시 키워드 없음.
   - 예: "좀비 피해서 3분 버티는 게임"
   - 예: "돌아다니며 코인 모으는 게임"
   - Claude 가 바로 받아서 컨셉 10줄 정리 + 시작용 스크립트 작성까지 해드립니다.
2. **Unity 열기**: Unity Hub에서 이 프로젝트 열고 표시된 씬으로 이동.
3. **Play 버튼 클릭**: 움직이는 캐릭터 확인.
4. **계속 얘기**: "점프 추가해줘", "적 넣어줘", "3분 타이머" 식으로 반복.

---

## 말하는 법 — 프롬프트 예시

| 하고 싶은 것 | 이렇게 말하면 됨 |
|---|---|
| 점프 기능 | "점프 기능 추가해줘" |
| 적이 따라오게 | "적이 플레이어를 따라오게 해줘" |
| 타이머 | "3분 뒤에 게임 끝나게 해줘" |
| 점수 UI | "UI에 점수 표시해줘" |
| 배경 음악 | "배경 음악을 넣을 수 있게 해줘" (음악 파일은 직접 넣어야 함) |
| 체력 | "적한테 맞으면 체력 줄어들게" |
| 이동 속도 | "플레이어가 너무 빨라, 느리게 해줘" |
| 색깔 바꾸기 | "플레이어 색을 빨간색으로 바꿔줘" |
| 버그 수정 | "점프하면 바닥으로 빠져, 고쳐줘" |
| 처음부터 | "다시 처음부터 시작할래" |

## 하면 안 되는 것

- ❌ **파일 삭제해달라고 하기** — 실수로 작업이 날아갈 수 있음
- ❌ **`main` 브랜치에 합쳐달라고 하기** — Proto에서만 작업
- ❌ **다른 브랜치로 이동** — 작업이 섞임
- ❌ **Unity MCP 서버 끄기** — Claude가 Unity를 조작하지 못 함
- ❌ **Git 직접 만지기** — Claude가 자동으로 커밋함 (push 는 사용자가 원할 때만)

---

## 막히면

- **`/help` 치기** — 지금 뭘 해야 할지 안내
- **"다시 처음으로"** 말하기 — 현재 작업 리셋
- **에러 나면** — 그냥 "에러 떴어" 하고 Unity 콘솔 텍스트 복사해 붙여넣기
- **Unity가 안 켜짐** — Unity Hub에서 이 프로젝트가 제대로 열려 있는지 확인

---

## 범위 제한

이 경량 버전은 **빠른 프로토타이핑 전용**입니다:

- ✅ 혼자 플레이하는 3분짜리 간단한 게임
- ✅ 1~2개 메커닉 (점프, 공격, 수집 등)
- ✅ 1개 씬, 1개 레벨
- ❌ 멀티플레이, 대규모 레벨, 복잡한 스토리, 저장/로드 시스템 (필요하면 `main`의 정식 워크플로 사용)

## 참고

- **Claude가 바로 코드를 씁니다** — "써도 돼?"라고 매번 안 물어봅니다. 다만 1줄 요약을 먼저 말합니다.
- **Git 자동 커밋** — 작업 끝날 때마다 Claude가 저장합니다. 너는 신경 안 써도 됩니다. 원격 서버에 올리는 `push` 는 **"푸시해줘"** 라고 직접 말했을 때만 실행됩니다.
- **Unity에서 Play만 누르면 됨** — 스크립트 컴파일은 Unity가 자동으로 합니다.
